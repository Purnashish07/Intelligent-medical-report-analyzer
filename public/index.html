AI & clinical safety

Honest limits for the prototype

This build uses deterministic, explainable rules—not a generative AI model. It does not infer diseases, rank severity, or recommend treatment. Adding a real AI service would require a secure server, explicit consent, privacy safeguards, validated medical sources and clinical evaluation.

⚠
Health and privacy notice

Educational prototype only; not a medical device. Do not enter real patient identifiers. PDF extraction is local in the browser. Example ranges can differ from a lab's range and may not fit an individual. For actual results, consult a qualified healthcare professional.

Frequently asked questions

What this version can and cannot do

Does it diagnose a medical condition?

No. It extracts PDF text and checks values against sample limits. It does not diagnose or predict disease.

Will every PDF work?

Only text-based PDFs are likely to work. Scanned reports need OCR, which is not included in this version. Always review extracted text carefully.

Is the uploaded report sent to a server?

The PDF extraction runs locally in your browser. The current project does not upload report files to its backend.

Project details

Static frontend plus optional local API

Built with HTML, CSS and JavaScript, plus PDF.js for in-browser text extraction. The optional Node.js backend exposes a health-check endpoint and a transparent rule-analysis endpoint. No API keys or external AI services are required for the demo.
